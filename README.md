# 🎰 AI 로또 번호 생성기

**https://adjust5162-star.github.io/lotto-generator/**

과거 당첨 빈도 기반 가중치 추천과 OpenRouter AI 추천 두 가지 방식으로 로또 번호를 생성합니다.

## 기능

- **번호 5세트 생성** — 자주 출현한 번호에 가중치를 적용해 5세트 추천
- **AI 추천** — OpenRouter API를 통해 AI가 번호 1세트 추천 (첫 사용 시 API 키 입력 필요)

## AI 추천 사용법

1. [openrouter.ai/keys](https://openrouter.ai/keys)에서 API 키 발급
2. "✨ AI 추천 받기" 버튼 클릭 후 키 입력
3. 키는 브라우저 localStorage에만 저장되며 외부로 전송되지 않습니다
